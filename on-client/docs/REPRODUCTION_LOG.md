## 4. 데이터 보존, 백업 및 복원 계획 (Data Preservation & Backup Plan)
- **백업 위치**: 로컬 작업 디렉토리 내 `.git` 저장소 및 원격 GitHub 저장소 (`https://github.com/qja742482/kesev-defense.git`)
- **백업 방법**: 정기적인 소스 코드 변경 사항 스테이징(`git add`), 커밋(`git commit`), 그리고 원격 푸시(`git push`)를 통한 버전 관리 백업.
- **복원 순서**: 
  1. 기존 작업 디렉토리 유실 시 새로운 빈 폴더 생성
  2. `git clone https://github.com/qja742482/kesev-defense.git .` 명령으로 소스 코드 복원
  3. `cd on-client` 후 `npm install`을 실행하여 의존성 재구축
  4. `npm start`로 로컬 서버 및 상태 복원 완료
- **데이터 백업 제한 사항**: 로컬 테스트 환경의 일시적 세션 상태, 메모리 캐시 및 실시간 일시적 진단 로그는 영구 저장되지 않으며 서버 재기동 시 초기화됩니다. 외부 AI 게이트웨이(CLCO) 연동 이전의 로컬 데이터는 수동 백업 외에 자동 원장 백업을 지원하지 않습니다.

## 5. 지원 범위 및 제한 사항
- **지원 범위**: 본 릴리스는 Windows PowerShell 환경 및 Node.js v24.19.0 기반 로컬 개발 서버 (`http://127.0.0.1:5189`)에서의 수동 검증 및 데모 환경을 지원합니다.
- **미해결 및 제한 사항**: 실제 프로덕션 계정 자동 프로비저닝, 유료 AI 실시간 연동, 원격 실집행 조치 및 클라우드 자동 배포는 지원 범위에서 제외됩니다.
