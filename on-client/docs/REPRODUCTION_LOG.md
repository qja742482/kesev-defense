## 2. 새 환경 재현, 종료 및 재실행 절차 (Clean Environment Reproduction & Restart Verification)
새로운 빈 폴더에서 동일한 환경을 재현하고 검증한 절차와 관찰 결과는 다음과 같습니다.

1. **클론 및 폴더 이동**
   - 명령: `git clone https://github.com/qja742482/kesev-defense.git .` 후 `cd on-client`
   - **관찰 결과**: 소스 코드가 정상적으로 클론되며 프로젝트 디렉토리 진입 완료.
2. **의존성 설치 및 최초 서버 기동**
   - 명령: `npm install` 후 `npm start`
   - **관찰 결과**: `alekov-client-starter@0.2.14` 서버가 `http://127.0.0.1:5189`로 구동되고 대시보드 화면 렌더링 확인.
3. **앱 종료 후 재실행 절차 및 관찰 결과**
   - **종료 절차**: 터미널에서 `Ctrl + C`를 입력하여 실행 중인 로컬 서버 프로세스 중지.
   - **재실행 명령**: `npm start` 재입력.
   - **관찰 결과**: 서버가 정상적으로 재기동되며, 초기 상태의 대시보드와 학생 구현 컴포넌트(`student/extension.mjs`)가 다시 문제없이 로드됨. (단, 이전에 발생했던 일시적 세션 캐시는 초기화됨)
