| 항목 | 내용 |

| 디스크 표시 | `C:\` → `C:` (한글 글꼴에서 ₩로 보이던 문제) |

### 「다시 조회」의 한계 (정직하게)

서버(`src/`)를 고치지 않았으므로 버튼은 **새로 측정하지 않고 서버가 가장 최근에 잰 값을 다시 받음**.

| 영역 | 서버 측정 주기 | 버튼을 눌렀을 때 값의 나이 |
|---|---|---|
| ① 내 PC 자원 | 30초 | 최대 30초 전 |
| ② 내 PC 보안 구성 | 5분 | 최대 5분 전 |

그래서 버튼 이름을 "최근 측정값 다시 조회"로 하고, 값마다 실제로 잰 시각을 표시함.

### 실패 이유별 다음 할 일

| 실패 이유 | 화면에 보여 주는 다음 할 일 |
|---|---|
| 첫 측정 중 | 몇 초 뒤 다시 조회 |
| 앱 서버에 연결하지 못함 | 서버 창에서 npm start 확인 후 다시 조회 |
| 10초 안에 응답 없음 | 잠시 뒤 다시 조회, 계속되면 서버 창 오류 확인 |
| 관리자 권한 필요 | 일반 권한에서는 확인 불가가 정상, 설정을 바꾸지 않음 |
| PowerShell 실패 | 일반 PowerShell 창에서 Get-NetFirewallProfile 실행 확인 |
| SDP 미연결 | 기존 서버·에이전트 연결 어댑터 확인 (docs/SDP_HOST_CONNECTION.md) |

### 키보드 사용

| 요소 | 방법 |
|---|---|
| 바로가기 · 다시 조회 | 진짜 `<button>` → Tab 이동, Enter·Space 실행 |
| 바로가기 이동 | 해당 영역 제목(`<h3 tabindex="-1">`)으로 초점 이동 |
| 대기·결과 알림 | `role="status"`, `aria-live="polite"`, 조회 중 `aria-busy="true"` |
| 기록 상세 | `<details>/<summary>` → Enter·Space로 열고 닫기 |
| 그림 막대 | `aria-hidden`, 같은 값을 글자로 함께 표시 |
