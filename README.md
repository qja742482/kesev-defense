\# 케셰브(Kheshav) 보안 Agent



이 PC의 자원(CPU·메모리·디스크), 보안 구성(네트워크·방화벽·Windows 기록), 연결 상태를

관제 대시보드 형태로 보여 주는 로컬 보안 앱입니다. 설치 포장 없이 프로젝트 폴더에서 바로 실행합니다.



\- 모든 조회는 \*\*일반 권한, 읽기 전용\*\*입니다. 방화벽·보안 설정을 바꾸지 않습니다.

\- 값마다 \*\*실측 · 잰 시각\*\*이 붙고, 못 읽은 값은 \*\*확인 불가 + 이유\*\*로 보입니다.

\- Windows 기록 건수는 \*\*침해나 공격 탐지 결과가 아닙니다.\*\*



\## 준비물



| 항목 | 확인 방법 | 필요한 값 |

|---|---|---|

| Windows + PowerShell | 시작 메뉴에서 "PowerShell" 실행 | 일반 권한 (관리자 아님) |

| Node.js | `node -v` | `v24.19.0` |

| Git | `git --version` | 아무 버전 |



외부 npm 패키지는 없습니다. `npm install`은 필요 없습니다.



\## 실행 (처음 보는 사람용, 5단계)

PowerShell 창을 열고 아래 명령을 **한 줄씩 입력한 뒤 Enter**를 누릅니다. `#`으로 시작하는 줄은 설명이라 입력하지 않아도 됩니다.

```powershell

\# 1. 받기 (원하는 폴더에서)

git clone https://github.com/qja742482/kesev-defense.git

cd kesev-defense



\# 2. 앱 폴더로 들어가기 ← 꼭 필요합니다. 이 위치에는 실행할 파일이 없습니다.

cd on-client



\# 3. Node 버전 확인 (v24.19.0)

node -v



\# 4. 서버 켜기

npm start

```



5\. 아래 문구가 나오면 그 창은 \*\*닫지 말고 그대로 두고\*\*, 브라우저에서 `http://127.0.0.1:5189`를 엽니다.



```text

케셰브 연결 확인: http://127.0.0.1:5189

```



끄기: 서버 창에서 `Ctrl + C`



\## 성공했는지 확인



왼쪽 메뉴 \*\*보호 현황\*\* → 아래로 내려 \*\*학생 상태·알림 표시\*\* 영역을 봅니다.



| 보여야 하는 것 | 의미 |

|---|---|

| 핵심 기능: ① 내 PC 자원 · ② 내 PC 보안 구성 · ③ 연결·알림 상태 (버튼) | 내 영역이 정상으로 불러와짐 |

| ① CPU · 메모리 · 디스크 카드에 `실측 · 오전 ○○:○○:○○` | 이 PC에서 실제로 잰 값 |

| ② 네트워크 · 방화벽 · Windows 기록 카드에 `실측`, SDP 카드에 `SDP 미연결` | 정상 (SDP 서버에 연결하지 않은 기본 상태) |

| 각 영역의 「최근 측정값 다시 조회」 버튼 | 누르면 "조회 중…" → "조회 완료 · 시각" |



화면 예 (값은 \*\*예시\*\*이며, 실제 값은 PC마다 다릅니다):



```text

① 내 PC 자원 — 이 PC에서 직접 잰 값   \[최근 측정값 다시 조회]  조회 완료 · 오전 11:41:34

&#x20; CPU 사용률 13.8 %  · 실측 · 오전 11:41:26

&#x20; 메모리 사용량 9 / 15.8 GB (56.8 %) · 실측 · 오전 11:41:26

&#x20; 디스크 남은 공간 345.1 GB 남음 (C:) · 실측 · 오전 11:41:25

```



\## 자주 막히는 곳



| 증상 | 원인 | 해결 | 확인 여부 |

|---|---|---|---|

| `npm error enoent Could not read package.json` | 저장소 맨 위 폴더에서 실행함 | `cd on-client` 후 다시 `npm start` | 실제로 겪고 확인함 |

| `계정 연결 설정을 확인하지 못했습니다` (start-alekov.ps1 실행 시) | 시작 도구가 선택 기능인 계정 연결(AI 연결)을 준비하다 멈춤 | 계정 연결 없이 쓰려면 `npm start`로 실행 | 실제로 겪고 확인함 |

| 화면 맨 위 빨간 상자에 `ENGINE\_NOT\_CONNECTED` 5줄 | SDP 서버(기존 서버·에이전트)에 연결하지 않은 기본 상태 | 고장이 아닙니다. 내 PC 조회 기능은 그대로 동작 | 실제로 확인함 |

| 새 카드가 안 보이고 예전 화면이 나옴 | 브라우저·서버가 예전 파일을 기억함 | 서버를 껐다 켜고 브라우저에서 `Ctrl + Shift + R` | 실제로 겪고 확인함 |

| Security 기록이 `확인 불가` | 관리자 전용 기록 | 정상. 일반 권한에서는 읽지 않습니다 | 실제로 확인함 |

| `EADDRINUSE ... 5189` | 다른 창에서 이미 서버가 켜져 있음 | 그 창에서 `Ctrl + C` 후 다시 실행 | 아직 직접 겪지 않음 |



계정 연결·AI 연결까지 쓰려면 `on-client/docs/STUDENT\_LAUNCH\_GUIDE.md`를 따르세요 (선택 사항).
